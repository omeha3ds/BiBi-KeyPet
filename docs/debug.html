Чому такий настрій

1. Спить?→ asleep
2. Рідкісна картка (stoned / pinkeye, приблизно раз на місяць)
3. Стан: батарея без зарядки
4. Післясмак нещодавньої події
5. Яка потреба нижче своєї межі найсильніше
6. Ніч (22–6) та енергія < 0.5?→ sleepy
7. Чим зайнятий: прокинувся, гуляє, на зарядці
8. Загальне самопочуття (валентність) → палітра дня
Поверх цього — короткі реакції: погладили, тицяння (angry → furious → rage → swearing), тряска, подмухали, гучний звук, упустили, догори дриґом, знайомство (love / shy / suspicious / angry / belligerent), дзвінок (yes / no / puzzled), ігри, годування.

їжа енергія веселощі увага прогулянки валентність
