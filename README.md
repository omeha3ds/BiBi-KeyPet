# bibi — розумний брелок-улюбленець

**bibi** живе в круглому AMOLED-брелоку: реагує на дотики, нахили й настрій, показує сповіщення з iOS-телефона, керує музикою, працює бейджем, QR-візиткою, пультом для презентацій, шумоміром та має колекцію міні-ігор і 6 фірмових палітр (Сакура, Онікс, Лагуна, М'ята, Персик, Іній) у двох стилях очей — Звичайні та Liquid.

*English below.*

## Панель керування та прошивка

**Найпростіший спосіб:** відкрийте в Chrome або Edge **[https://omeha3ds.github.io/BiBi-KeyPet/](https://omeha3ds.github.io/BiBi-KeyPet/)**, підключіть брелок USB-C кабелем (з передачею даних), натисніть **«Підключити по кабелю»**, а далі налаштуйте ім'я бейджа, посилання Quick QR, палітру, стиль очей або оновіть прошивку у вкладці **«Прошивка»**.

**Підключення до iOS-телефона:** Налаштування → Bluetooth → **bibi**, далі підтвердіть код на екрані брелока верхньою кнопкою й дозвольте показ сповіщень.

## Можливості bibi

- **Живий характер:** понад 45 емоцій і реакцій — гладьте, трусіть, перевертайте екраном донизу, дмухайте на нього, знайомте з людьми.
- **Стиль:** 6 кольорових палітр (Сакура, Онікс, Лагуна, М'ята, Персик, Іній) і перемикач очей **Звичайні / Liquid**.
- **Додатки:** годинник, догляд за bibi, Quick QR (до 4 посилань), бейдж, шумомір, таймер, секундомір, ліхтарик, Bluetooth, сповіщення, музика, камера (спуск затвора), пульт для презентацій, екран «Про пристрій» та міні-ігри (кулька, хрестики-нулики, магічна куля, монетка, кубик, лабіринт).
- **Приватність та енергозбереження:** сповіщення приховані до відкриття, чутливі повідомлення (коди, паролі, банки) не зберігаються; автосон і режим енергозбереження.

## Для розробників

Репозиторій: **<https://github.com/omeha3ds/BiBi-KeyPet>**

- `ui/` — переносимий C + LVGL 9.5, спільний для прошивки (ESP-IDF 5.5) та вебсимулятора.
- `firmware/` — прошивка для ESP32-S3-Touch-AMOLED-1.75C.
- `docs/index.html` — вебпанель керування та прошивки (Web Serial / Web Bluetooth).
- `sim/` — локальний та WebAssembly-симулятор (`sim/build-web.ps1`, `sim/serve.py`).
